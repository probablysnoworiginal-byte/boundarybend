# BoundaryBend

This repository is the curated public reading edition of **BoundaryBend**, a game world and design project by Preston.

Browse the published site at:

<https://probablysnoworiginal-byte.github.io/boundarybend/>

The site contains selected worldbuilding, game-design writing, visual direction, and interactive canvases. Private working notes, raw sources, local tools, and project-management material are intentionally not included.

The site is built with [Quartz](https://quartz.jzhao.xyz/). Quartz is available under its own license; BoundaryBend's original writing and creative material remain © 2026 Preston. See the site's copyright notice for terms.
